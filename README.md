# Expense Tracker (ASP.NET Core MVC + Entity Framework In-Memory)

A simple web-based Expense Tracker application built using **ASP.NET Core MVC** and **Entity Framework Core (In-Memory)**. This project allows users to perform basic CRUD operations (Create, Read, Update, Delete) on expenses.

## Features

- Add new expenses
- View a list of all expenses
- Update existing expenses
- Delete expenses
- Data is stored in-memory (no persistent storage)

## Technologies Used

- ASP.NET Core MVC
- Entity Framework Core (In-Memory Database)
- Razor Pages
- Bootstrap (for basic styling)
